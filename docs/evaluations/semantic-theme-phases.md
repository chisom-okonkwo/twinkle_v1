## A — Baseline and rubric

Existing collection-level processing completed with zero saved groups. pgvector is available (0.8.2), not installed. No passage-level design is justified by this length distribution.

The existing engine compares a 32-note fresh window plus up to 16 bridge candidates using one strict text-model request.
