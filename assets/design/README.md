# Design preview assets

Photographs are bundled locally so the screen preview does not need an image service at runtime. These are sample photos from Unsplash, not user content.

- [Books photograph](https://images.unsplash.com/photo-1507842217343-583bb7270b66)
- [Lake photograph](https://images.unsplash.com/photo-1470770841072-f978cf4d019e)
- [Coffee photograph](https://images.unsplash.com/photo-1442512595331-e89e73853f31)

The small line icons are original white PNG masks at 4× resolution, tinted by React Native at runtime. They support native and web without adding an icon or SVG dependency.
